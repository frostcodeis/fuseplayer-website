# FusePlayer 1.0, build 5: library materials

FFmpeg and jcifs-ng source packages and complete bundled notices are supplied here. The relinking archive is split into six parts, each at most 18 MiB. Download all parts plus relink-parts.json and Join-RelinkParts.ps1, then run the joining script to verify and reconstruct the ZIP.

Read relink.html and the reconstructed archive README for build requirements and instructions. Use your own signing key for modified APKs. The optional Movie of the Night integration requires the user's own API key; no shared publisher MOTN key is supplied in build 5.

Contact: frostcodeis@gmail.com.

OpenSubtitles.com requires each user's own API key. Neither the retired OpenSubtitles application key nor the retired Movie of the Night key is included in build 5 materials.
